## 交互流程

1. 进入“质量策略”，选择左侧“全局限制”。
2. 启用额外收录条件；首次启用得到待完成的空组，不会自动保存为固定通过。
3. 在组标题选择“全部条件”或“任一条件”；该选择只修改当前组。
4. 每一行依次选择字段、判断关系、比较值和自动匹配的单位；需要嵌套逻辑时使用“添加子组”。
5. 用“复制”“包为子组”“删除”“删除整组”和“撤销上一步”完成结构编辑。
6. 先阅读规则摘要，再用已有候选或手工样本执行只读测试。
7. 仅在规则完整且测试结果符合预期后保存；停用、清空和保存分别表达不同意图。

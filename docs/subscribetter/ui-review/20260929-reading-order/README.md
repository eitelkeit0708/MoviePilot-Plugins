# 文案、密度与视觉层级修订

本轮保留已有主导航、页面关系、业务能力和服务端操作保护。依据用户最新反馈，修正同权重信息过多、页面流程难读、依赖分割线分组的问题。

## 设计与实施

- 首屏只保留当前对象、关键状态、主要操作。状态异常、配置冲突、共享影响和删除后果保持直接可见。
- 页面标题、内容组标题、字段标签、辅助说明形成四级字体与间距。用同组邻近、组间留白和轻微表面差异表达关系；分割线只用于数据行或固定操作区。
- 订阅：接管已有订阅作为主要动作，常用状态与搜索常驻，完整筛选按需展开；分集说明移入明确的阅读帮助。
- 质量策略：明确分为“允许哪些资源”和“优先选择哪个版本”，排序操作收敛为有名称的图标按钮；全局锁定、额外条件和共享规则分组，复杂条件操作按需展开。
- 下载方案：保留现有步骤，概览分开基础用途与质量选择；名称替换词、规则细节与清理核对信息按需展开。
- 榜单、上传与设置：统一页面与内容组层级，改写实现术语，缩短常驻说明。正常状态不使用警告面板。

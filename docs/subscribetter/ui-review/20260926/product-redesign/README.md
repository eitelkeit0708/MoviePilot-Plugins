## 本轮实际变化

- 五个业务域保留，模式变成短状态提示。作品全宽详情使用紧凑抬头、三个页签，低频动作收进作品操作。
- 每集按「库内版本 / 本轮升级 / 进展与下一步」排列。可信字节计数才显示百分比；秒传使用有效未命中次数和服务端到期时间；未知外部结果突出核对要求。
- 同一候选的相同结论按实际返回集号合并；部分摘要标出覆盖数；完整依据按需读取，数值排序后分页。
- 编辑一份方案时退出十二组全局设置导航，只保留五个步骤和一套底部操作。逐步检查缺项，显示实际共享字段影响、整份设置的保存范围。
- 一次「保存方案」串接原有预检、MoviePilot 原生保存和生效回读。响应未知锁定重复写入；继续核对结果。浏览器草稿保留，修改后立即撤销旧成功提示。
- AI 使用「保存连接与设置 / 测试连接」，组合显示未配置、保存中、部分成功、待测试和测试结果。显式测试允许生产 AI 关闭，但保持预算、管理员权限和配置代际校验。
- 现场发现并修复：电影被写成集数、候选详情字符串排序、取消等待被写成待确认、多媒体库恢复操作错误地指向第一份映射。

# 用户应该怎样操作

这份说明描述最终产品的入口和步骤。截图中的服务、作品及路径是隔离测试环境示例，不是推荐生产目录。本轮实机复核只读；以下涉及保存、启用、下载的步骤不是声称已经执行。

## 首次配置一份下载与入库方案

1. 在 MoviePilot 先配置下载器、下载目录、媒体服务器，并安装配置可用的 CD2/115 适配插件。插件读取这些现有服务；选择器显示不可用时，先在宿主修复对应服务。
2. 打开 subscriBetter 数据页 → **设置 → 下载与入库方案**。输入一个能说明用途的名称，例如“电视剧升级”，点击 **新建方案**。
3. **下载与分类**：选 MoviePilot 分类、下载器、下载目录和收录升级策略。界面自动维护方案内部关联。若要修改策略本身，到“独立策略”；同一分类共享所选策略。
4. **云盘与写入范围**：选择已有 CD2/115 实例，填写云盘根目录和允许写入范围。115 父目录映射在高级项；没有正确映射不能跳过后端检查。
5. **媒体库与播放路径**：选 Emby 服务和真实媒体库名称，填写四段路径：Emby 所见 STRM → MP 可读取 STRM；STRM 内播放路径 → CD2 内部路径。路径使用全宽输入。新配置无扫描样本时，先完成配置并保存，按同页提示进入“扫描与恢复”，产生样本后回来检查。
6. **暂存与整理**：填 115 暂存目录、Symedia 接收入口及监控范围。暂存必须在监控范围外。确认这条交付规则是否启用；普通上传和清理权限仍在高级项明确配置，不自动开启。
7. **检查并保存**：核对下载器、目录、分类、暂存、入口和运行状态。点击 **检查这份草稿**；错误出现时留在当前草稿修改。通过后点击页面底部 **保存设置**。检查通过不是保存成功，也不是路径实测成功。
8. 保存后重新进入第 3 步，展开 **用真实档案检查映射**，读取该库扫描记录、选择实际作品、点击 **检查这条映射**。没有样本不填写虚构 ID；按提示先建立扫描记录。
9. 到 **基本设置与自动接管** 选择是否启用追踪、是否演练、接管哪些新订阅。先核对范围和策略，再切换执行模式。本轮隔离环境仍为未启用追踪、演练打开。

编辑已有方案只需在同一入口选择名称，沿同样五步修改。看到“其他方案也在使用”时，修改云盘或路径会影响所列共享范围。切换步骤不会保存；底部关闭/离开前应处理尚未保存的草稿。

## 新增作品与日常查看

1. 在 MoviePilot 原生搜索/订阅页面添加作品。插件没有另造一套媒体订阅身份接口。
2. 若需接管已有原生订阅，在插件 **订阅 → 纳管已有订阅** 选择作品及已配置方案，核对身份后提交。自动接管则按已保存类型和权限执行。
3. 回到订阅列表，用片名、状态和类型筛选。行内查看最近在库记录、当前处理、下一步；点击作品打开全宽详情。
4. **分集与版本**：左侧识别集号，中间看已确认在库版本，右侧看本轮目标规格及依据、阶段、进展、下一步。必要时展开“文件与采样详情”。“未取得”需要等待新采样或核查服务，不是零进度。
5. **候选比较**：先看有界摘要；点击“查看本次比较依据”才读取完整记录。正文说明每个目标的结果与关键比较维度，原始数据在折叠项。它是当时的比较记录，不能替代当前在库状态。
6. **处理记录**：显示最新五条计划，时间最新在上；阶段明确为历史记录。继续调查可进入底部诊断入口。
7. 点击 **返回列表** 回到原筛选和滚动位置。本轮实测了一个非零位置及键盘焦点恢复；没有把它泛化为所有设备通过。

## 文件正在下载、等待秒传或等待整理

1. 从作品详情右列看目标规格和当前阶段，或进入 **传输与待处理** 查看交付包。
2. 下载显示当前目标所需文件的测得字节；跨集文件会说明。秒传显示逐文件已确认未命中次数和记录的上限。
3. CD2 已发送字节不能当成云端完成。发布结果未知时先核对；没有明确下次时间时不会承诺几分钟后执行。
4. 交付之后等待 Symedia 整理及媒体库确认；旧在库版本与本轮处理分开显示。历史入库成功不代表新版本已完成。

## 榜单发现

1. 设置 **榜单与 RSS**，填写自部署 RSSHub，选择内置豆瓣榜单或自定义路由；`@@TV`/`@@Movie` 是类型提示。
2. 保存后回 **发现** 查看作品；管理已保存来源时可原位试读，结果直接显示。改动未保存时不能拿旧来源的成功替新草稿背书。
3. 需要新增订阅仍交给宿主原生接口，身份、权限和方案检查照常执行。

## 可选 AI 名称辅助

1. 到 **AI 名称辅助** 填服务、模型和密钥，点击 **应用连接信息到草稿**。密钥进入私密存储，普通草稿只保存引用。
2. 检查“连接信息已私密保存”和“页面设置与已保存配置一致”两项；若页面有修改，点击底部保存。
3. 需要使用时启用 AI 并保存，再点 **测试已保存的模型连接**。这会发真实请求并可能消耗额度；“连接参数已配置”本身不代表模型可用。
4. 页面分别显示私密写入、配置一致性和本次模型响应。部分失败不会伪装成整个步骤成功。本轮没有启用或请求模型。

## 出错时

- 候选依据读取失败：在原位置重试，不把失败显示成“没有记录”。
- 草稿检查/保存失败：原输入保留，按错误修改；不要重新建一份掩盖错误。
- 媒体库名称暂不可用：保留已保存选择，修复宿主连接后重新读取，不要求用户编辑内部 ID。
- 旧目标规格未记录：显示未知；新计划建立后才有完整冻结规格。
- 高级诊断：用于追查原始记录和受控操作，不是日常配置的主入口。

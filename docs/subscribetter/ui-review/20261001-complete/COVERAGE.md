## 数据与环境

- 页面：`plugins.v3/subscribetter/frontend/dev/index.html`，启动方式为在 frontend 目录运行 `npm run dev -- --host 127.0.0.1 --port 4179`；空白配置使用 `?blank=1`。
- 基准提交：`2fb389ee9c3e15b1cd4ca962ce85b4ce2a3a2bbd`。本次为截图补齐 `/archive/targets/` 的合成版本记录响应，避免版本记录页面因预览响应缺项而无法展示。未修改生产组件或样式。
- 浏览器视口：1280 × 720。截图原始像素尺寸为 1265 × 712 或 1264 × 720，由当前截图接口返回；文件没有二次缩放。浏览器内核具体版本未记录。
- 内部滚动容器无法靠一张整页截图展开，因此使用连续分段。保留实际页头、页脚、保存栏、焦点框和预览顶栏；相邻画面重复属于覆盖重叠。
- 规则目录展示默认规则。表单示例、资源名称、媒体库、下载器和路径均来自合成预览；新增共享规则名为“截图示例 WEB 资源”。
- 榜单运行记录、统计、可接管订阅没有合成记录，图册如实展示空状态。未伪造这些模块的有数据状态。
- 同等优先截图覆盖选择和合并后的展示，并显示拆开入口；这份图册不作为拖拽、刷新持久化或全部配置组合的功能测试报告。
- 所有截图的名称、所属模块、主题、视口、内部滚动位置、文件尺寸和哈希位于 [manifest.json](manifest.json)。

# 用户实际如何使用这套界面

对应正式代码 `62275c4`。以下是操作路径，不代表每项真实业务已在本轮执行。初次配置先保持演练；设置保存成功、路径检查成功、云端文件存在、实际入库成功是不同结果。

## 1. 第一次配置一份下载与入库方案

1. MoviePilot → 插件 → subscriBetter → 查看数据 → 设置 → 下载与入库方案。也可从插件设置直接进入同名分组。
2. 输入自己能识别的名称，点“新建方案”。系统分配稳定身份；之后可改显示名称，不必重建方案。
3. 第一步“下载与分类”：选 MP 已发布的真实影视分类、现有下载器和 MP 容器可用下载目录。选收录与升级策略，展开完整规则核对允许分辨率、维度顺序、锁定及调度。一个 MP 分类共用一份策略；修改共享条件时页面列出其他受影响方案。
4. 第二步“云盘与写入范围”：选择已有 CD2、115 插件实例，填写云盘根和允许写入的路径。这里只引用已登录的宿主服务，不让用户搬运服务密钥。
5. 第三步“媒体库与播放路径”：选 Emby 服务和实际媒体库名称，填写下面四个**前缀**。同一云盘范围已有多个媒体库时会同时列出，需要核对每个共享映射。

| 输入 | 含义 | 脱敏后的本地路径示例 |
|---|---|---|
| Emby 中的 STRM 路径前缀 | Emby 返回的 .strm 所在目录 | `/emby/strm/review/Movies` |
| MP 可以读取的 STRM 路径前缀 | 同一批 .strm 在 MP 容器的挂载目录 | `/mp/strm/review/Movies` |
| STRM 内容中的播放路径前缀 | .strm 文本里视频路径的本地挂载前缀 | `/mnt/cd2/CloudDrive/115/review/media` |
| CD2 内部文件路径前缀 | 上述视频在 CD2 API 内的位置 | `/115/review/media` |

这些路径已经脱敏，不能直接用于实际容器的挂载。长路径可就近展开全文。不是把完整电影文件名填进前缀字段。

6. 点击“选择样本”，在本页最多 25 部作品中选一部，点击“检查当前路径”。成功后逐段核对完整结果。无样本时先在该 Emby 库建立一份 STRM，再重新读取。若提示读取范围未授权，继续完成方案并保存，再回第三步检查；保持演练/关闭即可。不要为了检查去开启全局扫描。
7. 第四步“暂存与整理”：填写 MP 本地整理入口、115 暂存目录、Symedia 接收目录和监控范围。暂存与接收目录应按部署用途分开；授权只覆盖自己选择的范围。清理权限在独立分组，不随目录填写自动开启。
8. 第五步“检查并保存”：核对关联、共享影响、运行方式和这次整份配置的保存范围。点“保存方案”，等待“设置已保存并确认生效”。失败保留草稿；结果未知时先核对，不重复提交。
9. 若第三步此前缺读取授权，现在返回检查。四段路径通过只证明转换和 STRM 读取成功，仍需按既有流程核对 CD2、Symedia、Emby 实际交付。
10. 路径与服务准备好后，在“基本设置与自动接管”决定是否启用追踪、是否退出演练、哪些新订阅自动接管、哪些已有库寻找更好版本。正式启用前阅读已有方案及独立清理权限。

## 2. 添加订阅与日常看进展

1. 在 **MoviePilot 原生搜索/媒体详情**创建订阅。插件不另造媒体订阅创建流程。
2. 已设置自动接管类型的订阅按规则进入插件；已有订阅可在插件“订阅 → 接管已有订阅”中选择作品及方案，查看预览后确认。
3. 列表先看作品、收录范围、具体集号与当前动作。总数未知时只能知道已收录数量，不能据此判定整季完成。
4. 点作品进入全宽详情。桌面比较当前与目标；手机先读变化摘要，展开查看全部版本。多项提升可以同时标紫，偏好降低的维度单独标示。发布者明确字幕声明不等于已完成最终文件鉴定。
5. 下载时看实际字节与百分比；秒传看已确认未命中次数和真实下次时间。没有测得的数据保持未知。
6. 某集“结果待核实”时，在那一集点“核对结果”。这次仅观察外部状态，不能因点击结束就认为上传成功；仍未知则保留当前版本，不重新上传或清理。
7. “候选比较”按资源及影响的集数查看允许、拒绝或等待。展开单次比较才加载完整依据；读取失败保留摘要，点“重新加载”只重读详情。
8. “处理记录”查看最近计划。返回列表保留当前筛选；隔离宿主已验证一次非零滚动与焦点恢复，任意设备/筛选组合仍需额外实机验收。
9. 暂停、恢复、交还 MP 在作品操作中执行，按预览核对作用范围。它们不是删除现有视频的快捷方式。

## 3. 豆瓣发现

1. 设置 → 榜单与 RSS，填自部署 RSSHub 根地址，选择内置豆瓣榜单；自定义路径可带 `@@TV` / `@@Movie` 类型后缀。
2. 为来源填写可读名称、选择分类及下载方案，检查已有策略与范围后保存。
3. 在保存的来源旁试读，看抓取及身份识别结果；试读不等于已经订阅/下载。
4. “发现”默认看作品及处理结果，用来源筛选；需要改来源时展开管理来源。旧来源变更状态与当前抓取失败分别显示。
5. 缺少可靠身份时查看详情、等待冷却或按现有操作重新判定，不为追求订阅数量自动猜测 TMDb 身份。

## 4. 传输与入库

1. 传输列表按作品定位交付，点开查看文件、字幕、发布及入库状态。
2. 未知结果用就近“核对结果”；等待 Symedia/Emby 时只根据服务端记录判断，交付完成不等于入库确认。
3. 重试、放弃、清理仍需要原有范围预览与权限校验。无权限/结果未定时不能操作；UI 不会放宽后台限制。
4. 原始回执、文件证据、扫描记录放在详情或高级诊断供排障。

## 5. 策略与 AI

策略页先选分类，读允许范围、维度优先顺序及当前锁定。发布组、平台、片源条件可展开短解释，再展开精确规则；自定义规则不会伪装成内置默认。编辑在独立策略设置进行，保存后再读回。策略预演不发起下载。

AI 名称辅助设置同页填写地址、模型、密钥，按按钮将连接写入私密存储并进入草稿，再保存配置。私密写入和配置保存是两个事务：前一步成功、后一步失败时保留明确提示，不要求再暴露/搬运 secret 引用。配置实际启用及所有权检查通过后测试连接；测试会真实调用提供商。独立聊天功能已移除，MP 原生 Agent 不受影响。

## 6. 迁移旧插件

先备份旧配置，在“设置 → 迁移与处理者冲突”选择一种入口：

- **导入备份**：选择来源插件、版本、时区与不超过 2 MiB 的 JSON；预览字段映射，再确认逐批导入，每批最多 100 条。旧成功历史不自动变成当前在库事实。
- **读取旧榜单**：同页输入服务地址、凭据和允许访问的内网网段；保存连接并预览确切 GET 路径，确认后读取配置/历史，再进入导入预览。
- **切换功能**：读取当前旧插件，勾选受支持的旧功能以及将启用的新 AI/榜单。检查预览与冲突，按提示保存旧开关、核对，再携带切换记录进入配置保存。切换会启用插件并退出演练，已有订阅/交付也可能开始执行，不能把它当作纯粹的历史导入。

页面自动携带切换记录；未知/冲突不能强行继续。回退在高级区按既有流程执行。手工恢复记录、逐历史关联及完整证据仍可用，但不是普通首次配置所需步骤。本轮没有对真实旧插件执行切换。

## 7. 其余设置在哪里

| 分组 | 用户的选择 |
|---|---|
| 基本设置与自动接管 | 启用、演练、电影/剧集自动接管、媒体库勾选、保护片名 |
| 独立策略 | 完整分类策略、覆盖、锁定和准入条件 |
| 自动升级期限 | 电影/剧集持续追踪及完结后行为 |
| 站点与搜索 | 实际站点勾选、搜索条件；请求预算在高级区 |
| 等待与更换版本 | 观察、冷却、取代三组；0 次表示禁止替换 |
| 媒体库与整理路径 | 现有云盘/映射/交付规则的维护页 |
| 扫描与恢复 | 周期扫描与恢复设置，不是单次路径检查的前置开关 |
| 清理权限 | 成功清理、放弃清理、云端暂存、下载任务、下载数据分别授权 |
| 安全与容量 | 已有容量和保护限制 |
| 榜单与 RSS | 自部署来源、类型、方案关联、试读 |
| AI 名称辅助 | 连接、名称辅助、原生识别桥、提示词及诊断 |

如菜单点击不切换，或显示状态与真实 API 不一致，应按实际页面与版本登记缺陷；不要用本说明反过来认定界面一定正确。

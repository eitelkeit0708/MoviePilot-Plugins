# 三场景交互样板：先确定产品设计

日期：2026-09-27。正式插件基线仍为 `30c0bd1`，本轮没有替换隔离 V3 或生产插件。

**这一包是可点击的设计样板。不是已完成的正式前端，也不是业务验收通过报告。** 它按本轮要求先串起「订阅列表、分集升级、首次配置」，供人实际判断阅读顺序、视觉层级和操作是否顺畅。没有使用测试数量给设计打分。

## 运行和审阅

在仓库的 `plugins.v3/subscribetter/frontend` 目录执行 `npm ci`、`npm run dev`，然后打开：

`http://127.0.0.1:4179/dev/study-review.html`

这个地址同时提供桌面和 390px 手机画布，切换时保留同一页面状态。`dev/study.html` 是没有外围审阅工具栏的直接入口。

全部服务、样本和操作在浏览器内模拟，不发送 NAS 请求。没有引入新依赖；沿用 Vue、Vuetify 和现有质量格式化函数。样板位于 `dev/study/`，没有加入正式 Page/Config 的构建入口。ZIP 中的 `site/` 是静态构建，可在该目录运行 `python -m http.server 4180 --bind 127.0.0.1`，然后访问 `/dev/study-review.html`。

## 三条可连续体验的路径

1. **查看作品现在发生了什么**：订阅 →「需核对」或搜索作品 → GATE24 → 查看具体分集。列表列出实际目标，例如第 5 集待核对、第 1 集下载中、第 6 集上传中，不显示「几种进展」。查看后返回保留筛选，并恢复原作品的键盘焦点。
2. **理解这一集为什么升级**：分集行直接显示当前版、目标版与进度。样例由既有合成夹具构造，高亮依据是样板明确提供的「分辨率」比较结论；前端不推导其他维度孰优孰劣。展开详情后再看完整规格、字幕与证据来源。第 5 集的「核对结果」就在该集内；模拟读取之后仍显示未知，不伪装成成功。手机画布默认显示一行版本变化，展开才查看两套完整规格。
3. **从零完成一份方案**：下载与入库方案 → 新建 → 填名称、分类、下载器、目录与偏好 → 选云盘和写入目录 → 选媒体库并填写两段路径 → 选择样本、检查当前草稿 → 填暂存和 Symedia 入口 → 确认并保存。可使用桌面左下角「填入一份完整示例」走通示例流程，也可逐项输入。缺项会停在当前步骤。路径检查不要求全局追踪开启、不保存配置；修改路径或样本即撤销旧结果。最后可模拟保存失败，再恢复正常保存。

方案退出时可保留浏览器草稿；刷新后进入方案列表继续编辑。样板内方案的显示名称可改，内部 ID 不变。模拟保存只存在当前页面内，刷新不保留已保存方案；未保存草稿另存当前浏览器会话。这里没有实现正式配置持久化。

候选比较附带一个相邻场景：8/16 集摘要 → 按需读取完整结果；勾选「模拟详情读取失败」后展开，只提示加载失败并保留摘要。技术状态码位于错误详情，重试文案为「重新加载」。

## 这次确定的呈现规则

- 作品行以名称和收藏数量为主，重点动作优先；没有可靠海报时使用低调类型图形，没有为封面发起整库请求。
- 当前版本弱化，比较结论中明确的提升维度高亮。通用证据说明集中在一个入口，各集的特殊依据留在详情。
- 紫色表示正在执行或主要动作，金色表示待核对，暂停为中性状态。图标和文字共同表达，不只靠颜色。
- 分集操作就近呈现；未知结果核对与普通详情读取采用不同文案。
- 桌面并列比较，手机摘要展开。方案拥有独立步骤区和一套固定底部操作。

## 验证与限制

前端 `npm test` 本轮实际运行：**53 项通过，0 失败、0 跳过**。其中新增 1 项样板模型检查覆盖具体集号摘要、稳定 ID、逐步校验、路径边界及检查失效指纹；其余为既有前端回归。第一次受沙箱子进程限制，SQLite 夹具未启动；在允许启动本地 Python 的环境重跑相同命令通过，没有降低断言。静态样板构建成功，正式插件构建产物未改变。

浏览器实际执行并检查了：列表打开/返回的键盘焦点；手机摘要展开；单集模拟核对；候选读取失败；空白步骤校验；草稿路径成功与不匹配；改路径清除旧成功；五步保存；模拟保存失败保留输入；保留草稿后实际刷新并恢复。路径结果曾位于视野外，已补上检查完成后滚到结果。

截图来自 Codex 内嵌浏览器的默认桌面视口，具体尺寸在 `capture.json`。手机是 **390px 宽的同源嵌入画布**，不是手机设备。高 DPI 尺寸覆盖会产生裁切或平铺，本包未收录这些异常图；没有重绘、拼接或修改截图内容。原图保留外围审阅工具栏及浏览器捕获的上方留白。真实触摸、读屏、200% 缩放和稳定鼠标坐标通道未验收，不能用键盘操作替代这些结论。正式宿主嵌入效果也未验证。

AI 连接页、发现、传输、全部高级设置未在此样板中重做；正式产品目前仍使用上一版。这一轮没有真实下载、上传、清理、调用 DeepSeek 或修改远端配置。所有截图和界面都是合成数据。

## 设计确认后必须接入的正式合同

以下是下一阶段的实现要求，**不是本包已经具备的后端能力**：

| 项目 | 正式接入要求 |
|---|---|
| 作品重点动作 | 由有界只读投影提供具体目标与阶段，显示已覆盖范围；不能用六条样本概括整季。 |
| 版本变化 | 使用服务端实际比较结论和证据来源，不在浏览器重新比较质量或解析文件名。 |
| 就近操作 | 接入现有授权、代际、回执和结果未知保护；固定样例 actions 不是权限依据。 |
| 样本读取 | 在已授权 Emby 服务/媒体库内有界读取一页；不触发全库扫描，不建立订阅。 |
| 草稿路径检查 | 使用当前草稿与所选真实样本，只读检查；文件读取仍受已有可信路径根和安全读取约束，任意草稿前缀不能获得额外本地文件权限。结果绑定草稿指纹。 |
| 方案名称 | 正式 Destination 增加独立显示名称，旧 ID 作为缺省显示；所有现有引用继续使用稳定 ID。 |
| 保存 | 继续原有整份配置预检、原生保存和精确回读。实际共享影响与其他未保存改动要展示出来；本样板的独立模拟保存不能取代该合同。 |
| 全面推广 | 在三场景设计确认后，把同一组件规格应用于 AI、发现、传输和其余设置，保留原有业务与高级能力。 |

## 如何运行和检查

仓库：在 `plugins.v3/subscribetter/frontend` 执行 `npm ci`、`npm run dev`，访问 `http://127.0.0.1:4179/dev/study-review.html`。

独立包：在解压后的 `site` 目录运行 `python -m http.server 4180 --bind 127.0.0.1`，打开 `http://127.0.0.1:4180/dev/study-review.html`。顶部切换桌面/390px 画布时保留当前页面。

1. **订阅列表**：GATE24 显示「已收录 7 集 · 总集数待确认」；侠女内莉的示例明确提供可靠总数，显示 2 / 6。另一个作品刻意提供已知 6 集、已收录 6 集但总数未知，不能显示为整季完成。
2. **GATE24 → 分集与版本**：逐集检查下表，切换到手机画布，重点看第 3、4、7、8 集。展开详情查看完整规格。这里的八个目标不是整季总集数。
3. **第 5 集 → 核对结果**：模拟结果仍未知，显示这次浏览器模拟检查完成时间、暂无自动检查安排，以及不可用的重新上传/清理暂存及原因。时间不是远端操作时间。
4. **下载与入库方案 → 新建**：先点下一步观察必填项；填名称、选择 MP 分类示例、下载器和目录。策略跟随所选分类，展开「查看完整规则」。可用桌面左侧「填入一份完整示例」继续体验。
5. **媒体库与路径**：四个字段都是目录前缀。选择第 1 集样本后检查，结果显示下方四段完整路径。更改任一映射字段或样本，旧结果消失。将 STRM 内容前缀改错再检查，显示具体不匹配原因。
6. **确认方案**：复核分类和策略，模拟保存失败后输入保留；关闭失败开关再保存。模拟保存只在当前页面内存在。未保存草稿存于当前浏览器会话，可以退出保留后刷新恢复。

## 版本变化样例

| 集 | 明确给定的事实 | 主行应表达 |
|---|---|---|
| 1 | 决定性维度为分辨率 | 1080p → 4K |
| 2 | 同为 4K，决定性维度为画面 | SDR → Dolby Vision |
| 3 | 分辨率、画面相同，决定性维度为音频 | DDP → 无损音频 |
| 4 | 质量相同，字幕依据更新 | 中文 PGS 推断 → 明确特效声明；不是新的画质档 |
| 5 | 分辨率升级，云端结果未知 | 就近核对，未知状态不变 |
| 6 | 同分辨率、同画面，音频升级正在上传 | DDP → 无损音频；云端进度未取得 |
| 7 | 明确确认缺集，首次下载 | 尚未在库 → 待下载版本 |
| 8 | 已达到当前偏好，没有在途计划 | 已收录；展示正常当前版本 |

`change.kind/dimensions/reason` 是给定的合成判断事实，代替未来真实服务端投影。组件不比较质量数值，不从文件名推断优劣。格式化复用正式 `media.mjs`。当前实现覆盖上表的分辨率、画面、音频与字幕依据；其他复合比较维度接入时仍需定义准确的展示合同，不能把这八个样例当作所有实际状态。

## 本地 STRM 主链路

```text
Emby STRM 文件（示例容器目录）
/strm/series/GATE24/S01E01.strm
  ↓ 第一段前缀映射
MP 可读 STRM 文件（示例容器目录，未验证真实挂载）
/media/strm/series/GATE24/S01E01.strm
  ↓ 模拟读取所选样本内容
/vol3/1000/docker/clouddrive2/CloudNAS/CloudDrive/115/series/GATE24/S01E01.mkv
  ↓ 第二段前缀映射
CD2 API 内部路径
/115/series/GATE24/S01E01.mkv
```

本轮移除了 HTTP 主样例。检查器只做合成字符串映射，不读取真实 STRM 或检查文件存在。正式接入仍必须限制管理员身份、所选服务/媒体库与可信读取根，草稿前缀不能扩大本地文件权限。

## 分类与完整策略

向导保存稳定的分类 ID、策略 ID 与版本引用，未再创建「4K/1080p 优先」两套简化规则。三个分类是明确标注的离线样例，媒体类型另作说明；没有声称已经获取 MP 当前分类。

`policies.json` 由 `export_policies.py` 调用实际 `Policy.describe` 导出，包含欧美剧、国产剧、动画电影的准入摘要和完整比较顺序；观察/冷却取自仓库默认配置。未配置的时间显示「未设置」，取代上限 0 显示禁止自动取代。完整规则保留中文条件、发布组、片源、字幕、音频、观察/冷却、适用的同分例外与技术定义。选择国产剧时不显示为适用字幕同分例外。

这是一份可复现的仓库默认策略快照，不是用户 NAS 保存策略。正式接入应复用 `/configuration/categories`、`/policies` 等现有只读数据，将实际锁定、覆盖、自定义准入和调度设置一起带入展示。策略编辑仍属于已有完整策略配置能力，本轮没有另建简化编辑器。

更新快照（仓库根目录，使用已有安装 regex 的 Python 环境）：


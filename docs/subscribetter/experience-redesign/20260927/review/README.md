## 图片与验证边界

- 截图工具返回 JPEG 字节，临时文件曾命名 .png；公开时仅改为正确的 .jpg 后缀，没有重新编码、缩放或裁剪。哈希、文件大小、实际像素见 [manifest.json](manifest.json)。
- 390px 为浏览器 CSS 视口，原始截图像素由工具返回，二者不可混作同一个指标。不是物理手机或真实触摸验证。
- 保存位置与时间是截图写盘信息，不冒充后台事件发生时间。
- 02/03/04 的真实子策略保存和最终恢复见 [nested-save-readback.json](evidence/nested-save-readback.json)。
- 稳定鼠标及键盘的非零滚动结果，以及首次不完全相同的记录均在 [scroll-return.json](evidence/scroll-return.json)。
- [deployment.json](evidence/deployment.json)同时记录 Windows 部署源字节 SHA256 与固定 Git 提交字节 SHA256。98 个文本文件仅存在 CRLF/LF 差异，已逐项确认；139 个部署文件均与安装端一致。
- 32 号截图来自发现旧“全部版本档案”入口问题时，未作为最终截图公开；33/34 展示修复后的实际入口和单集历史。
- 19 号“重载后草稿”缺少当时 loader 变化证据，不纳入跨真实重载 PASS。完整报告列为 NOT_RUN。

# 如何使用本轮界面

适用于本目录 IMPLEMENTATION.md 指向的产品提交。普通订阅新增仍从 MoviePilot 的电影／电视剧订阅页面进入。下面描述实际入口；服务权限、路径和版本判断仍由后台校验。

## 日常查看与处理作品

1. 在 MP 插件页打开 subscriBetter 的“查看数据”。默认进入“订阅”。从“全部／处理中／需核对／已暂停”、类型或片名筛选作品。
2. 点作品行进入详情。没有可靠总集数时，页面只显示已收录集数，不显示整季完成比例。已有可信封面时使用封面，缺少时显示类型图标。
3. “分集与版本”同时显示在库版本、本轮目标、当前进度。紫色只标出后台确认的改善；同一次升级的多项改善同时显示，偏好降低单独标黄。详情中可查看完整规格、证据来源和文件。
4. 需要核实时，在相应集点击“核对结果”；查询完成仍可能是未知，不等于上传成功。“更换资源”先显示精确影响范围，再由后台决定能否确认。它不是删除文件按钮。
5. “候选比较”先看本资源能补哪些集、升级哪些集和哪些不处理；展开后读取完整比较依据。已排除资源可以在此查看并预览撤销。
6. “处理记录”显示最近五个计划；“全部版本记录”按页查看该集的库内历史。高级诊断保留原始依据。
7. “作品操作”可暂停、恢复或交还 MP；返回列表恢复筛选、滚动和原作品焦点。

## 从作品连续修改策略和方案

1. 在作品标题下点击当前分类策略或下载方案，进入已经选定的对象。
2. 策略页先显示使用范围。修改允许分辨率、发布组与片源准入、比较顺序；“所有策略的限制”明确是共享条件。
3. 在同页选择已有候选，或填样本标题。“试算本次修改”使用当前草稿；“检查当前生效策略”使用保存值。修改草稿后，旧试算结果撤销。
4. 保存后核对生效结果，再用返回按钮回原作品或外层方案。方案未保存的其他输入保留。
5. 如果在方案内保存了共享策略，再放弃方案草稿，策略继续生效。放弃确认会列出本次已经保存的子编辑；需要撤销策略时重新编辑策略，不做跨保存操作的假回滚。
6. 遇到并发冲突，界面保留当前输入，列出冲突字段的保存值与本地修改。核对后再决定保留；不会静默覆盖。

## 新建一份下载与入库方案

1. “下载方案”→ 输入可读名称 →“新建方案”。内部身份自动建立；以后可改显示名称。
2. **用途与版本**：选择 MP 真实分类及完整质量策略，可直接进入所选策略调整。共享分类的影响会显示。
3. **下载**：选择宿主下载器、下载保存目录和站点。这里是下载器的目录。
4. **上传与整理**：选择现有 CD2、115 连接及授权云盘范围；分别填写“从哪里上传”（MP 整理后的目录）、115 暂存目录、Symedia 接收目录。下载目录和上传来源不自动互填；有意相同时仍须通过后台验证。目录选择不会附带清理权限。
5. **媒体库与路径检查**：选择 Emby 服务与媒体库，填写四个路径前缀：Emby STRM → MP 可读 STRM；STRM 本地挂载路径 → CD2 内部路径。“选择样本”读取一页真实作品，再检查当前草稿。未授权的新读取范围需要先保存授权，再检查；无需启用正常追踪或扫描。
6. **检查并保存**：核对下载目录、上传来源、云端目录、共享影响及当前运行模式。保存只提交本方案及本次明确修改的关联设置，包含删除；其他方案草稿不夹带提交。
7. 保存结果未知时保留输入，并提供“核对保存结果”；不会自动再发一遍。单次路径转换通过不等于文件已经在云端，也不等于下载、整理和入库已完成。

## 榜单和上传

- **榜单**：先看作品及收录结果；已识别、已管理、交回 MP、媒体库已有、尚未加入分别表达。筛选来源后可进入相关作品。“管理来源”就在本页进入；填自部署 RSSHub 地址，选择内置豆瓣路由或自定义来源。“试读榜单”只抓取；“运行一次／重新检查收录条件”会按保存规则重新处理，执行前明确范围。
- **上传与入库**：只负责整理后的上传、发布、消费者整理与媒体库确认。先按作品查看，再展开批次、文件。下载阶段从“查看作品与下载进度”返回作品页。未知结果、取消、清理各自使用不同的后台许可；不能从一种按钮状态推断另一种动作也被允许。

## 全局设置与高级能力

| 分区 | 使用方式 |
|---|---|
| 运行与自动管理 | 启用追踪、演练模式、电影／电视剧自动接管、按实际名称选择自动升级的媒体库、追踪期限 |
| 搜索与等待 | 勾选站点；分别设置下载前观察、在途替换、入库后冷却，0 次明确表示禁止替换 |
| 名称识别 | 片名保护与 AI 辅助同页保存。新地址／密钥先私密写入，配置保存和连接测试分别反馈；历史密钥不回显。未启用时保存不会顺带发送模型请求 |
| 媒体库检查 | 选择定期检查的库和检查预算；单个方案路径检查仍在方案里完成 |
| 维护与安全 | 成功、放弃、下载器任务、下载器数据分别授权；导出安全配置、导入备份、读取旧榜单和切换功能从此进入 |

诊断保留完整资源分页、不可变操作预览和恢复依据。普通配置不要求编辑原始对象；复杂自定义条件仍有专用条件编辑器，少见复合值在高级区保留完整表达能力。迁移预览不等于切换生效；AI 私密存储与普通配置保存不是同一事务。

## 本轮环境限制

隔离 V3 保持 `enabled=false / dry_run=true`。这轮验证主要是界面连续操作、只读查询及可恢复的策略保存。新上传、115 秒传、真实触屏和完整生产链路未因这些界面测试重新放行。具体证据和未测项见 IMPLEMENTATION.md。

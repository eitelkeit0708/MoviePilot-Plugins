# subscriBetter 交互 Flow 与 UX 设计

## 设计目标

界面只让用户管理作品、版本、处理进度和设置结果。内部 ID、原始对象、回执和完整审计证据只在对应问题的详情或诊断中出现。

导航的职责固定为：

1. 一级导航选择业务：订阅、榜单、上传与入库、质量策略、下载方案。
2. 设置左侧二级导航选择模块：运行管理、搜索与调度、名称识别、媒体库检查、维护与安全。
3. 内容顶部三级页签选择当前对象的一个方面。页签切换真实面板，不滚动到长表单中的某段。
4. 保存区固定说明本次提交范围；不同模块的草稿不随当前保存一起提交。

## Flow 1：查看作品与处理具体分集

```text
订阅列表
  → 搜索 / 状态筛选（输入与已应用条件分开）
  → 选择作品
  → 分集与版本 / 候选比较 / 处理记录
  → 当前版本 + 目标版本 + 差异 + 进度 + 下一步
  → 就近执行当前允许的操作
  → 返回列表并恢复筛选、页码、滚动位置和焦点
```

- 列表先显示作品、已收录范围和最重要的当前状态。
- 当前版本与多个候选目标由后台事实决定；前端不重新计算质量。
- 候选和处理记录读取失败时，分集基础详情仍可阅读。
- 版本历史在分集下方跨列展开；已知 0、未知、读取失败分别表达。

## Flow 2：从榜单发现作品

```text
榜单作品
  → 来源 / 处理结果筛选
  → 查看作品
  → 返回榜单并恢复来源、筛选、页码和焦点

榜单
  → 来源设置 / 运行记录 / 统计
  → 原位查看人类可读摘要
```

- 作品是默认主角，来源设置是同一业务的配置面板。
- “已识别”“已纳管”“待处理”保持不同含义。
- 统计展示条目、目标、结果和时间范围；原始统计对象留在维护诊断。

## Flow 3：检查上传与入库

```text
上传与入库
  → 按阶段筛选作品
  → 展开作品处理批次
  → 查看单个批次
  → 文件、上传状态、Symedia / 媒体库确认
  → 核对结果 / 继续当前阶段 / 取消交付 / 清理预览
  → 返回作品或批次列表
```

- 页面覆盖下载完成后的上传、整理和入库确认，不冒充完整下载任务中心。
- 普通等待、结果未知、服务不可用和已确认完成使用不同文案与操作。
- 只展示受支持的视频与文本字幕；IDX/SUB、独立字体和许可证不进入必要项、分母或阻塞。
- 取消交付不等于删除下载任务或文件；清理必须先读取服务端预览。

## Flow 4：查看、修改和试算质量策略

```text
选择策略
  → 规则 / 试算 / 使用范围 / 全局限制
  → 修改当前草稿
  → 试算当前草稿（显示策略、分类、模式和配置版本）
  → 保存质量策略模块或放弃本地草稿
```

- 保存前显示具体修改对象：策略模板、分类绑定、全局锁定或限制。
- 选择未绑定策略时，不把上一分类的已生效结果标成当前策略结果。
- 草稿或样本变化会使旧试算失效；迟到响应不能进入新上下文。
- 排序提供上移、下移按钮和键盘路径，不依赖拖拽。

## Flow 5：建立或维护下载方案

```text
选择方案
  → 概览
  → 下载（下载器、下载保存到）
  → 上传与整理（从哪里上传、115 暂存、Symedia 接收）
  → 媒体库与路径（Emby → MP → STRM 内容 → CD2 API）
  → 清理与保留
  → 保存当前方案
```

- 下载保存目录与上传来源是两个字段，不自动互填。
- 方案引用策略、云盘范围和媒体库映射；界面维护引用，用户不搬运内部 ID。
- 嵌套编辑保存的共享策略继续生效；放弃外层方案只放弃外层未保存草稿。

## Flow 6：修改设置

```text
设置
  → 左侧选择模块
  → 顶部选择功能页签
  → 只显示当前功能面板
  → 固定底部查看保存范围
  → 放弃修改 / 保存当前模块
```

设置结构：

| 二级模块 | 三级页签 |
| --- | --- |
| 运行管理 | 运行模式、订阅接管、升级期限 |
| 搜索与调度 | 站点与搜索、候选观察、资源替换、升级冷却、失败恢复 |
| 名称识别 | 解析修正、AI 服务、提示词与版本、缓存与限流 |
| 媒体库检查 | 检查范围、检查计划、路径检查、异常恢复 |
| 维护与安全 | 清理权限、资源限制、备份与迁移、诊断 |

- 保存和测试连接是两个动作；普通保存不隐含模型请求。
- 历史密钥不回显；显隐只作用于本次新输入。
- 诊断不再打开第二套业务 UI，只提供当前运行快照和有界排障入口。

## 响应式与可访问性

- 桌面以横向比较为主；移动端先给版本变化和进度摘要，再按需看完整证据。
- 390px 和 320 CSS px 下，主内容单列重排；一级导航可独立横向滚动，正文无横向溢出。
- 返回、保存、当前状态和异常操作在窄屏仍可到达。
- Tab / Shift+Tab / Enter / Space 可完成一级导航、页签、版本展开和规则排序。
- 焦点样式与悬停样式同时覆盖导航和操作，不把颜色作为唯一状态信号。

## 状态表达

| 事实 | 页面表达 |
| --- | --- |
| 正常等待 | 说明等待对象和下一次检查，不使用失败色 |
| 结果未知 | 保留已知事实，提供“核对结果”，不自动重发 |
| 服务不可用 | 保留旧内容并标记过期；重试只读取状态 |
| 保存结果未知 | 查询原回执，不重新提交保存 |
| 没有记录 | 静态空态，不提供无意义的展开按钮 |
| 数量未知 | 明确“尚未取得”，不显示为 0 |
| 权限不足 | 解释禁止的具体动作和影响范围 |

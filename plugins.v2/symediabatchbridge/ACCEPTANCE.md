| 问题 | 修复 |

| 整理记录读取故障阻塞全队列 | 补读失败保留游标，已入队批次继续执行 |
| 事件与工作线程覆盖彼此状态 | 使用同一进程间锁；忙时事件由整理历史补读恢复 |
| 上传中新增已知字幕直接停工 | 移交前纳入新增附件，保留已有 HASH、上传回执与重试次数 |
| 大批次重启后重复算 HASH | 每文件持久化，每轮限定计算/上传数量 |
| 同名同大小内容覆盖未检出 | 首次封存核对下载源内容；已封存内容改变时暂停交付 |

## 仍需明确的自动化边界

1. Symedia 没有向本插件返回归档完成回执。移动响应丢失且源/目标同时不可见时，无法证明目录已被消费；只能继续核对和通知，不能靠猜测重发视频。
2. 本插件等待本次已知下载/整理清单。批次移交后才产生的外来字幕或新选集数，不会自动补送，因为 Symedia 无视频时不处理字幕。
3. 账号授权失效、人工删除源文件、错误目录配置和内容冲突不能凭重试修复。插件会保留记录、定期再查并通知；不承诺这些情形下零人工。
4. 单文件普通上传依赖 MP 储存提供者的超时与退出行为。停用会阻止后续移交，不能强行中断正在进行的宿主上传。

下一轮完整验收应在隔离的 Symedia 输入/归档目录中，使用有效下载任务与视频/字幕，覆盖同名第二批、附件迟到、上传/移动中断和实际归档结果，并持续验证 24 小时秒传等待。
